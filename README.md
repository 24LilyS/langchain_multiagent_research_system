# langchain_multiagent_research_system
Multiagent research system using langchain

1. Install miniconda and ensure to check the box of including in path variable during the installation
2. create conda environment in the terminal: conda create -n langagent python=3.11 -y
3. actiavte the environment in the terminal : conda activate langagent
4. run in the terminal pip install -r requirements.txt
